# TechBridge Institute — IT Training Programs Landing Page

A multi-section responsive landing page for a fictional IT training institute, built as a front-end capstone project.

**Live demo:** https://danbryanleoncito.github.io/WebProject2/

## Overview

TechBridge Institute is a static, fully responsive marketing site for an IT education provider, showcasing a full catalog of certificate programs across software development, data science, cybersecurity, and IT infrastructure — along with student testimonials, an about section, and a contact form.

## Features

- Responsive navigation bar (Home, Categories, About)
- Auto-rotating testimonial carousel with student reviews
- 12 program cards across two categories:
  - **Software Development & Engineering** — Full Stack Web Development, Data Science & Machine Learning, Mobile App Development, AI & Deep Learning, UI/UX Design, Blockchain Development
  - **IT Infrastructure & Security** — Cloud Computing & DevOps, Cybersecurity, Network Engineering, Database Management, IT Project Management, Software QA & Testing
- About section outlining the institute's mission
- Contact form with name, email, and message fields
- Embedded Google Maps location
- Fully responsive layout across desktop, tablet, and mobile breakpoints

## Tech Stack

- **HTML5** — semantic page structure
- **CSS3** — custom styling and responsive layout
- **Bootstrap** — carousel component, card grid, and navigation
- Deployed on **GitHub Pages**

## Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/danbryanleoncito/TechBridge-Institute.git
   ```
2. Open `index.html` directly in your browser — no build step or dependencies required.

## Notes

This was built as a front-end-only capstone project to practice responsive layout design, card-based content structuring, and third-party embeds (Google Maps) using Bootstrap.
